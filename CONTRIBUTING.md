# Contributing to EXEscript

Thanks for taking an interest in EXEscript.

The application source code is not currently published, so source-code pull requests are not being accepted yet. Contributions are still welcome through bug reports, compatibility findings, documentation corrections, and feature suggestions.

When reporting a bug, include the Windows version, target architecture, application mode, selected PowerShell runtime, and clear reproduction steps. If a script is required to demonstrate the issue, reduce it to the smallest safe example possible.

Do not include credentials, access tokens, private business data, or confidential scripts in public issues.
